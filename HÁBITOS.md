
> [!info] # Habits — Used to / Be Used to / Get Used to

# 1. USED TO

### Structure

```
Subject + used to + Verb (base form) + Complement
```

### Use

- Hábitos que ocurrían regularmente en el pasado
- Situaciones o estados que eran ciertos en el pasado pero ya no lo son
- Contrastar una situación pasada con la situación actual

### Signal words

- in the past
- when I was young
- when I was a child
- years ago
- before
- formerly

### Examples

- I used to play soccer.
- She used to live in Mexico.
- They used to go to school together.
- He used to have long hair.

### Negative

```
Subject + did not + use to + Verb (base form) + Complement
```

- I didn't use to like coffee.
- She didn't use to live here.

> [!warning] Importante  
> Después de **did/didn't**, se utiliza **use to**, no **used to**.
> 
> + I didn't **use to** play soccer.
> 
> ❌ I didn't **used to** play soccer.

### Questions

```
Did + Subject + use to + Verb (base form) + Complement?
```

- Did you use to play soccer?
- Did she use to live here?

## 2. BE USED TO

### Structure

```
Subject + am/is/are + used to + Noun / Pronoun / Verb-ing
```

### Use

- Estar acostumbrado a algo
- Algo que ya resulta normal o familiar
- Hablar de una situación presente que no resulta extraña

### Examples

- I am used to the cold weather.
- She is used to working at night.
- They are used to waking up early.
- He is used to driving long distances.

> [!warning] Importante  
> Después de **be used to** usamos:
> 
> **Noun / Pronoun / Verb-ing**
> 
> ❌ She is used to work at night.
> 
> + She is used to **working** at night.

### Negative

```
Subject + am/is/are + not + used to + Noun / Pronoun / Verb-ing
```

- I am not used to the cold.
- She isn't used to working at night.

### Questions

```
Am/Is/Are + Subject + used to + Noun / Pronoun / Verb-ing?
```

- Are you used to working at night?
- Is she used to driving?

## 3. GET USED TO

### Structure

```
Subject + get + used to + Noun / Pronoun / Verb-ing
```

### Use

- Adaptarse gradualmente a algo
- Acostumbrarse a una situación nueva
- Describir el proceso de adaptación

### Examples

- I am getting used to the cold weather.
- She is getting used to working at night.
- They are getting used to living in a new city.
- He got used to waking up early.

### Negative

```
Subject + do/does/did + not + get + used to + Noun / Pronoun / Verb-ing
```

- I didn't get used to the cold weather.
- She doesn't get used to working at night.

### Questions

```
Do/Does/Did + Subject + get used to + Noun / Pronoun / Verb-ing?
```

- Did you get used to living there?
- Does she get used to working at night?

## 4. BE GETTING USED TO

### Structure

```
Subject + am/is/are + getting used to + Noun / Pronoun / Verb-ing
```

### Use

- Estar en proceso de acostumbrarse a algo
- Enfatizar que la adaptación está ocurriendo actualmente

### Examples

- I am getting used to waking up early.
- She is getting used to her new job.
- They are getting used to living alone.

## Quick Comparison

|Structure|Meaning|After "to"|
|---|---|---|
|**used to**|hábito pasado|Verb (base form)|
|**be used to**|estar acostumbrado|Noun / Verb-ing|
|**get used to**|acostumbrarse|Noun / Verb-ing|

### Examples

**USED TO**

> I **used to play** soccer.

→ Solía jugar fútbol.

**BE USED TO**

> I **am used to playing** soccer.

→ Estoy acostumbrado a jugar fútbol.

**GET USED TO**

> I **am getting used to playing** soccer.

→ Me estoy acostumbrando a jugar fútbol.
