


> [!info] # Quantifiers


## 1. SOME

### Use

- Se utiliza principalmente en oraciones afirmativas
- Puede utilizarse con sustantivos contables en plural.
- Puede utilizarse con sustantivos incontables. 
- Indica una cantidad indefinida.

### Structure

```
Some + Plural Countable Noun
```

```
Some + Uncountable Noun
```


### Examples

- I have **some books**.
- She bought **some apples**.
- We need **some information**.
- There is **some water** in the bottle.

> [!info] Questions  
> **Some** también puede utilizarse en preguntas cuando ofrecemos algo o esperamos una respuesta afirmativa.
> 
> - Would you like **some coffee**?
> - Can I have **some water**?

## 2. ANY

### Use

- Se utiliza principalmente en preguntas.
- Se utiliza principalmente en oraciones negativas.
- Puede utilizarse con sustantivos contables en plural.
- Puede utilizarse con sustantivos incontables.

### Structure

```
Any + Plural Countable Noun
Any + Uncountable Noun
```

### Examples

- Do you have **any questions**?
- Are there **any students** here?
- I don't have **any money**.
- There isn't **any water**.

### Questions

- Do you have **any information**?
- Are there **any problems**?

## 3. EVERY

### Use

- Se refiere a todos los miembros de un grupo considerados **individualmente**.
- Se utiliza solamente con sustantivos contables en singular.
- Expresa frecuencia o totalidad.

### Structure

```
Every + Singular Countable Noun
```

### Examples

- **Every student** has a book.
- I study English **every day**.
- **Every house** has a door.
- She goes to the gym **every morning**.

> [!warning] Importante  
> Después de **every** utilizamos un sustantivo **singular**:
> 
> ✅ every student
> 
> ❌ every students

## 4. NO

### Use

- Indica ausencia de cantidad.
- Puede utilizarse con sustantivos contables en plural.
- Puede utilizarse con sustantivos incontables.
- La oración con **no** ya tiene significado negativo.

### Structure

```
No + Plural Countable Noun
No + Uncountable Noun
```

### Examples

- There are **no students** in the classroom.
- I have **no money**.
- There is **no information** available.
- We have **no problems**.

> [!warning] Importante  
> No utilizamos otra negación después de **no**:
> 
> ❌ I don't have no money.
> 
> ✅ I have no money.
> 
> ✅ I don't have any money.

## 5. ALL

### Use

- Se refiere a la totalidad de un grupo o cantidad.
- Puede utilizarse con sustantivos contables en plural.
- Puede utilizarse con sustantivos incontables.

### Structure

```
All + Plural Countable Noun
All + Uncountable Noun
```

### Examples

- **All students** must take the exam.
- **All the students** passed.
- **All the information** was useful.
- I spent **all my money**.

### With singular noun

Para hablar de un grupo específico:

```
All + the/this/that/my/etc. + Noun
```

- All **the students**
- All **my friends**
- All **this information**

## 6. ONE

### Use

- Se refiere a una sola persona o cosa.
- Puede reemplazar un sustantivo contable singular ya mencionado.
- Puede utilizarse para evitar repetir un sustantivo.

### Structure

```
One + Singular Countable Noun
```

### Examples

- I have two cars. **One car** is red.
- Which book do you want? **The blue one**.
- One student answered the question.

### As a pronoun

```
Determiner + One
```

- I like the red **one**.
- I'll take this **one**.

## 7. EACH

### Use

- Se refiere a los miembros de un grupo **uno por uno**.
- Se utiliza con sustantivos contables singulares.
- Enfatiza a los individuos por separado.

### Structure

```
Each + Singular Countable Noun
```

### Examples

- **Each student** has a book.
- **Each person** received a ticket.
- **Each room** has a window.

### With OF

```
Each of + Plural Noun / Pronoun
```

- **Each of the students** has a book.
- **Each of them** has a different answer.
- **Each of the rooms** has a window.

> [!warning] Importante  
> Después de **each of** utilizamos un sustantivo o pronombre en plural, pero el verbo normalmente es singular:
> 
> **Each of the students is** ready.
> 
> No:
> 
> ❌ Each of the students are ready.

## 8. ONE OF

### Use

- Significa **uno de un grupo**.
- Se utiliza para seleccionar una persona o cosa de un grupo.

### Structure

```
One of + Plural Noun / Plural Pronoun
```

### Examples

- She is **one of my friends**.
- This is **one of the best books**.
- He is **one of the students**.
- One of **them** is my brother.

> [!warning] Importante  
> Después de **one of** utilizamos un sustantivo en **plural**.
> 
> ❌ one of my friend
> 
> ✅ one of my **friends**

## 9. EACH ONE OF

### Use

- Significa **cada uno de**.
- Enfatiza los elementos individualmente.
- Se utiliza para referirse a personas o cosas dentro de un grupo.

### Structure

```
Each one of + Plural Noun / Plural Pronoun
```

### Examples

- **Each one of the students** has a book.
- **Each one of them** received a certificate.
- I checked **each one of the answers**.

### Comparison

**Each of the students**

→ Cada estudiante individualmente.

**Each one of the students**

→ Cada uno de los estudiantes, con mayor énfasis en cada individuo.

## 10. EVERY ONE OF

### Use

- Significa **cada uno de / todos y cada uno de**.
- Se utiliza para referirse a todos los miembros de un grupo.
- Se utiliza con sustantivos o pronombres en plural después de **of**.

### Structure

```
Every one of + Plural Noun / Plural Pronoun
```

### Examples

- **Every one of the students** passed the exam.
- **Every one of them** was invited.
- I have read **every one of these books**.

> [!warning] Importante  
> No confundas:
> 
> **everyone** → pronombre = todos/todas las personas
> 
> **every one of** → cada uno de un grupo específico
> 
> Everyone was happy.
> 
> Every one of the students was happy.

## 11. FEW

### Use

- Se utiliza con sustantivos contables en plural.
- Significa **pocos**.
- Generalmente transmite una cantidad pequeña.

### Structure

```
Few + Plural Countable Noun
```

### Examples

- **Few students** passed the exam.
- I have **few friends** here.
- There are **few opportunities** available.

> [!warning] Few vs A Few
> 
> **few** → pocos, casi ninguno / cantidad insuficiente
> 
> **a few** → algunos, una pequeña cantidad pero suficiente
> 
> **Few students passed.**  
> → Pocos estudiantes aprobaron.
> 
> **A few students passed.**  
> → Algunos estudiantes aprobaron.

## 12. A LITTLE

### Use

- Se utiliza con sustantivos incontables.
- Significa **un poco de**.
- Indica una pequeña cantidad.

### Structure

```
A little + Uncountable Noun
```

### Examples

- I have **a little money**.
- There is **a little water** left.
- She has **a little experience**.

> [!warning] Little vs A Little
> 
> **little** → poco / casi nada
> 
> **a little** → un poco / alguna cantidad
> 
> **I have little time.**  
> → Tengo poco tiempo.
> 
> **I have a little time.**  
> → Tengo un poco de tiempo.

## 13. SEVERAL

### Use

- Se utiliza con sustantivos contables en plural.
- Significa **varios**.
- Indica una cantidad mayor que "a few", pero no necesariamente una cantidad grande.

### Structure

```
Several + Plural Countable Noun
```

### Examples

- **Several students** asked questions.
- I have visited **several countries**.
- She has **several books**.

## 14. VARIOUS

### Use

- Se utiliza con sustantivos contables en plural.
- Significa **varios / diversos / diferentes**.
- Enfatiza la variedad más que la cantidad exacta.

### Structure

```
Various + Plural Countable Noun
```

### Examples

- **Various students** participated in the competition.
- The university offers **various courses**.
- We discussed **various topics**.

> [!info] Several vs Various
> 
> **several** → enfatiza la cantidad
> 
> **various** → enfatiza la variedad
> 
> **Several students** attended the meeting.
> 
> → Asistieron varios estudiantes.
> 
> **Various students** attended the meeting.
> 
> → Asistieron estudiantes diferentes/diversos.


## 15. EVERYTHING

### Use

- Significa **todo / todas las cosas**. 
- Se refiere a todas las cosas de manera general.
- Es un pronombre, por lo que **no necesita un sustantivo después**. 
- Se utiliza con un verbo en singular.

### Structure

```
Everything + Singular Verb
```

### Examples

- **Everything is** ready.
- **Everything was** perfect.
- I remember **everything**.
- She knows **everything** about the subject.

> [!warning] Importante  
> **Everything** ya incluye el significado de "todas las cosas", por lo que no agregamos otro sustantivo después.
> 
> ✅ Everything is ready.
> 
> ❌ Everything things are ready.

## 16. EVERYTHING vs ALL

### EVERYTHING

**Everything** = todas las cosas consideradas como un conjunto.

```
Everything + Singular Verb
```

- **Everything is** ready.
- **Everything was** expensive.
- I ate **everything**.

### ALL

**All** = la totalidad de personas, cosas o una cantidad.

```
All + Noun
```

- **All the food is** ready.
- **All the students are** ready.
- **All the information is** useful.

## 17. ALL + DEFINITE NOUN

Cuando hablamos de un grupo o cantidad **específica/definida**, normalmente utilizamos:

```
All + the/these/those/my/your/etc. + Noun
```

### Examples

- **All the students** passed the exam.
- **All my friends** live here.
- **All these books** are mine.
- **All the information** was useful.
- **All this money** belongs to him.

Aquí sabemos **qué grupo o cantidad específica** estamos mencionando.

### Comparison

> **All the students** passed.

→ Todos los estudiantes **específicos** del grupo mencionado pasaron.

## 18. ALL + INDEFINITE / GENERAL NOUN

Cuando hablamos de personas o cosas de manera **general**, podemos utilizar:

```
All + Plural Countable Noun
All + Uncountable Noun
```

### Examples

- **All students** need education.
- **All dogs** need food.
- **All children** need attention.
- **All information** should be checked.
- **All money** has value.

Aquí no estamos hablando de un grupo específico, sino de la categoría **en general**.

### Comparison

**All students**

→ Los estudiantes en general.

**All the students**

→ Todos los estudiantes de un grupo específico.

## 19. EVERYTHING vs ALL — DEFINITE vs GENERAL

### General / Indefinite

```
Everything
All + Plural Noun
All + Uncountable Noun
```

- **Everything** is important.
- **All students** need practice.
- **All information** should be verified.

### Specific / Definite

```
All + the/this/that/my/etc. + Noun
```

- **All the students** passed the exam.
- **All my books** are on the table.
- **All this information** is useful.

> [!warning] Diferencia importante  
> **Everything** no necesita `the`, `my`, `this`, etc.
> 
> ❌ all everything
> 
> ❌ the everything
> 
> ✅ everything

## 20. EVERYTHING vs EVERY

No confundas:

### EVERYTHING

Es un **pronombre** y significa:

> todas las cosas

```
Everything + Singular Verb
```

- **Everything is** ready.
    

### EVERY

Es un **determiner** y necesita un sustantivo singular:

```
Every + Singular Countable Noun
```

- **Every student is** ready.
    

### Comparison

> **Everything is** expensive.

→ Todas las cosas son caras.

> **Every product is** expensive.

→ Cada producto es caro.

## Quick Comparison

|Structure|Meaning|Example|
|---|---|---|
|**everything**|todas las cosas|Everything is ready.|
|**every + singular noun**|cada elemento|Every student is ready.|
|**all + plural noun**|todos en general|All students need practice.|
|**all + the + plural noun**|todos los específicos|All the students passed.|
|**all + uncountable noun**|toda una cantidad general|All information is useful.|
|**all + the + uncountable noun**|toda la cantidad específica|All the information is useful.|

# Either / Neither

### 1. Either = uno de los dos / cualquiera de los dos ( + / -)

```
Either + Singular Noun
```

- Either answer is correct.
- Either option is possible.

### 2. Neither = ninguno de los dos (-)

```
Neither + Singular Noun
```

- Neither answer is correct.
- Neither option is possible.

> **Either = 1 de 2**  
> **Neither = 0 de 2**

---

### 3. Either ... or = una opción u otra

```
Either A or B
```

- Either John **or** Mary will come.
- You can either **stay or leave**.

> **Either → normalmente se relaciona con OR cuando presenta dos alternativas.**

---

### 4. Neither ... nor = ni una opción ni la otra

```
Neither A nor B
```

- Neither John **nor** Mary will come.
- She likes neither coffee **nor** tea.

> **Neither → NOR**

---

### 6. Either of / Neither of

```
Either of + Plural Noun
```

→ cualquiera de los dos.

> Either of the answers **is** correct.

```
Neither of + Plural Noun
```

→ ninguno de los dos.

> Neither of the answers **is** correct.

### Regla rápida

|Forma|Significado|
|---|---|
|**Either A or B**|A o B|
|**Neither A nor B**|Ni A ni B|
|**Either of...**|cualquiera de los dos|
|**Neither of...**|ninguno de los dos|
|**... negative + either**|tampoco|
