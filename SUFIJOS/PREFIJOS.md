
# Prefijos y sufijos

Aquí hay una diferencia fundamental:

**Prefijo (prefix)** → se coloca **antes** de la palabra.

> happy → **un**happy

**Sufijo (suffix)** → se coloca **después** de la palabra.

> happy → happi**ness**

Los prefijos normalmente modifican el **significado** de la palabra, mientras que los sufijos frecuentemente pueden cambiar su **categoría gramatical**.

Por ejemplo:

> happy → adjective  
> happiness → noun

---

#  Prefijos

|Prefijo|Idea principal|Equivalente aproximado en español|Ejemplo|Significado|
|---|---|---|---|---|
|**un-**|negación / contrario|in-, des-, no-|unhappy|infeliz|
|**dis-**|oposición / negación / separación|des-, dis-, in-|disagree|estar en desacuerdo|
|**mis-**|incorrectamente / mal|mal-, equivocadamente|misunderstand|malinterpretar|
|**de-**|quitar / revertir / reducir|des-, de-|deactivate|desactivar|
|**out-**|superar / estar fuera|sobre-, fuera-, más que|outperform|superar|
|**over-**|exceso / demasiado|sobre-, excesivamente|overwork|trabajar demasiado|

### UN-

Normalmente expresa **negación o lo contrario**.

- happy → unhappy
- important → unimportant
- clear → unclear
- fair → unfair
- known → unknown
- comfortable → uncomfortable

Piensa:

> **un- = no / contrario**

---

### DIS-

Puede expresar:

- oposición
- negación
- separación
- ausencia de acuerdo

Ejemplos:

- agree → disagree
- honest → dishonest
- appear → disappear
- connect → disconnect
- approve → disapprove

No siempre significa exactamente "no"; depende de la palabra.

---

### MIS-

Indica que algo se hace **incorrectamente o de manera equivocada**.

- understand → misunderstand
- use → misuse
- lead → mislead
- inform → misinform
- interpret → misinterpret

Una asociación útil:

> **mis- = mal / incorrectamente**

---

### DE-

Frecuentemente expresa **remover, reducir o revertir una acción**.

- activate → deactivate
- code → decode
- centralize → decentralize
- value → devalue
- motivate → demotivate

Pero no todas las palabras con `de-` tienen un significado que pueda deducirse perfectamente, así que úsalo como pista, no como regla absoluta.

---

### OUT-

Puede indicar:

- superar a alguien
- hacer algo mejor que otro
- estar fuera
- exceder

Ejemplos:

- perform → outperform
- grow → outgrow
- live → outlive
- number → outnumber

> outperform = superar en rendimiento

---

### OVER-

Generalmente indica **exceso** o algo que ocurre demasiado.

- work → overwork
- eat → overeat
- sleep → oversleep
- spend → overspend
- estimate → overestimate

> overeat = comer demasiado  
> overspend = gastar demasiado

---

# Sufijos

Estos son especialmente importantes para TOEFL porque te permiten **adivinar la categoría gramatical de una palabra**.

|Sufijo|Forma normalmente|Equivalente aproximado en español|Ejemplo|Resultado|
|---|---|---|---|---|
|**-er / -or**|persona que realiza una acción|-dor / -or / -ero|teacher|profesor|
|**-less**|ausencia de algo|-sin / -less|hopeless|sin esperanza|
|**-dom**|estado / condición / dominio|-dad / -dominio / -reino|freedom|libertad|
|**-hood**|estado / condición / etapa|-dad / -azgo / -edad|childhood|infancia|
|**-ness**|cualidad / estado|-dad / -eza|happiness|felicidad|
|**-ship**|estado / relación / condición|-dad / -azgo / -ción|friendship|amistad|
|**-ly**|manera / cualidad adverbial|-mente|quickly|rápidamente|
|**-ous**|característica / cualidad|-oso / -osa|dangerous|peligroso|

---

## -ER / -OR

Frecuentemente forma sustantivos que indican **una persona que realiza una acción**.

Equivalentes aproximados:

> **-er / -or → -dor / -or / -ero**

Ejemplos:

- teach → teacher
- work → worker
- drive → driver
- act → actor
- invent → inventor
- create → creator

Por ejemplo:

> teach → teacher  
> enseñar → profesor

> invent → inventor  
> inventar → inventor

No siempre se traduce literalmente con un sufijo español, pero la idea es **"persona que realiza una acción"**.

---

## -LESS

Expresa **ausencia de algo**.

Equivalente aproximado:

> **-less → sin**

Ejemplos:

- hope → hopeless → sin esperanza
- care → careless → descuidado / sin cuidado
- home → homeless → sin hogar
- help → helpless → indefenso / sin ayuda
- fear → fearless → sin miedo

Una regla muy útil:

> hope + less = sin esperanza

---

## -DOM

Normalmente expresa un **estado, condición, dominio o conjunto**.

Ejemplos:

- free → freedom → libertad
- king → kingdom → reino
- wise → wisdom → sabiduría

No tiene un único equivalente español. Puede relacionarse con:

> **-dad / estado / dominio / reino**

---

## -HOOD

Indica principalmente un **estado, condición o etapa de la vida**.

Ejemplos:

- child → childhood → infancia
- adult → adulthood → adultez
- brother → brotherhood → hermandad
- neighbor → neighborhood → vecindario

Equivalentes aproximados:

> **-hood → -dad / -edad / condición / etapa**

---

## -NESS

Es uno de los sufijos más importantes.

Normalmente convierte un **adjetivo en sustantivo**.

> adjective → noun

Equivalente aproximado:

> **-ness → -dad / -eza**

Ejemplos:

- happy → happiness → felicidad
- dark → darkness → oscuridad
- kind → kindness → bondad
- weak → weakness → debilidad
- aware → awareness → conciencia

Esta transformación es muy importante para TOEFL:

> happy = adjective  
> happiness = noun

---

## -SHIP

Normalmente expresa una **relación, estado, condición o posición**.

Equivalentes aproximados:

> **-ship → -dad / -ción / relación / condición**

Ejemplos:

- friend → friendship → amistad
- leader → leadership → liderazgo
- member → membership → membresía
- partner → partnership → asociación
- relation → relationship → relación

---

## -LY

Normalmente convierte un **adjetivo en adverbio**.

Equivalente aproximado:

> **-ly → -mente**

Ejemplos:

- quick → quickly → rápidamente
- slow → slowly → lentamente
- careful → carefully → cuidadosamente
- serious → seriously → seriamente
- complete → completely → completamente

Esta es una de las reglas más útiles:

> **Adjective + -ly → Adverb**

Pero recuerda que **no todos los adverbios terminan en -ly** y no todas las palabras terminadas en `-ly` son adverbios.

Por ejemplo:

> friendly = adjective  
> lovely = adjective

---

## -OUS

Normalmente forma **adjetivos** que expresan una característica o cualidad.

Equivalente aproximado:

> **-ous → -oso / -osa**

Ejemplos:

- danger → dangerous → peligroso
- fame → famous → famoso
- poison → poisonous → venenoso
- courage → courageous → valiente
- mystery → mysterious → misterioso
- religion → religious → religioso

Por tanto, cuando veas:

> **-ous**

puedes sospechar que la palabra es un **adjective**.

---

#  Lo más importante para TOEFL

Más que memorizar únicamente traducciones, intenta reconocer la **categoría gramatical** que produce cada sufijo:

|Sufijo|Probablemente produce|
|---|---|
|**-er / -or**|Noun|
|**-less**|Adjective|
|**-dom**|Noun|
|**-hood**|Noun|
|**-ness**|Noun|
|**-ship**|Noun|
|**-ly**|Adverb|
|**-ous**|Adjective|
