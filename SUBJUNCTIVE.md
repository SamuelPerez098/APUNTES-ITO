
# WISH / IF ONLY

`Wish` e `If only` se utilizan para expresar **deseos, arrepentimientos o situaciones que queremos que fueran diferentes**.

> **If only** tiene prácticamente el mismo significado que **wish**, pero suele expresar un deseo o arrepentimiento **más fuerte**.

---

# 2. Wish / If only + Present → Past Simple

Se utiliza para hablar de una situación **presente que no nos gusta o que queremos que fuera diferente**.

### Structure

```
Subject + wish + Subject + Past Simple
```

```
If only + Subject + Past Simple
```

### Examples

> I **wish I had** more money.

→ Ojalá tuviera más dinero.

> If only I **had** more time.

→ Ojalá tuviera más tiempo.

> She **wishes she lived** closer to work.

→ Desearía vivir más cerca del trabajo.

### Idea clave

```
PRESENT REALITY
       ↓
WISH + PAST
```

> I don't have enough money.  
> → I wish I **had** more money.

---

# 3. WISH / IF ONLY + WERE

Para situaciones hipotéticas con **be**, utilizamos normalmente `were`, especialmente en inglés formal.

```
Subject + wish + Subject + were
```

> I wish I **were** taller.

> I wish she **were** here.

> If only he **were** more careful.

La expresión más importante:

> **I wish I were you.**

→ Ojalá estuviera en tu lugar.

---

# 4. Wish / If only + Past Perfect

Se utiliza para expresar **arrepentimiento sobre el pasado**.

Algo ocurrió de una determinada manera y **ya no podemos cambiarlo**.

### Structure

```
Subject + wish + Subject + had + Past Participle
```

```
If only + Subject + had + Past Participle
```

### Examples

> I **wish I had studied** harder.

→ Ojalá hubiera estudiado más.

> If only I **had listened** to you.

→ Ojalá te hubiera escuchado.

> She wishes she **hadn't said** that.

→ Ojalá no hubiera dicho eso.

### Idea clave

```
PAST REALITY
       ↓
WISH + PAST PERFECT
```

> I didn't study.  
> → I wish I **had studied**.

---

# 5. Wish + Would

Se utiliza cuando queremos que **alguien o algo cambie su comportamiento**, normalmente porque algo nos molesta o nos resulta repetitivo.

### Structure

```
Subject + wish + Subject + would + Verb
```

### Examples

> I wish you **would listen** to me.

→ Ojalá me escucharas.

> I wish he **would stop** talking.

→ Ojalá dejara de hablar.

> I wish it **would stop** raining.

→ Ojalá dejara de llover.

> [!warning] Diferencia importante  
> Normalmente no utilizamos `wish + would` simplemente para hablar de nuestra propia capacidad o situación.
> 
> ❌ I wish I would have more money.
> 
> ✅ I wish I **had** more money.

La idea de `would` suele ser:

> **Quiero que algo/alguien cambie.**

---

# 6. Wish + Could

Se utiliza para expresar un deseo relacionado con **habilidad, posibilidad o capacidad**.

### Structure

```
Subject + wish + Subject + could + Verb
```

### Examples

> I wish I **could speak** English fluently.

→ Ojalá pudiera hablar inglés con fluidez.

> She wishes she **could travel** more.

→ Ojalá pudiera viajar más.

> If only I **could remember** his name.

→ Ojalá pudiera recordar su nombre.

---

# 7. Wish vs If Only

Prácticamente tienen las mismas estructuras:

|Situación|Wish|If only|
|---|---|---|
|Presente irreal|wish + Past|if only + Past|
|Arrepentimiento pasado|wish + Past Perfect|if only + Past Perfect|
|Querer cambio|wish + would|if only + would|
|Habilidad/posibilidad|wish + could|if only + could|

### Ejemplo

> I **wish I had** more time.

> **If only I had** more time.

Ambas:

→ Ojalá tuviera más tiempo.

La diferencia principal es de **énfasis**:

> **If only** suele sonar más fuerte o emocional.


# Resumen para memorizar

Esta es la parte que te recomiendo poner en tus apuntes:

```
PRESENT → WISH + PAST
```

> I wish I **had** more money.

```
PAST → WISH + HAD + PAST PARTICIPLE
```

> I wish I **had studied** more.

```
CHANGE / ANNOYANCE → WISH + WOULD + VERB
```

> I wish you **would stop** talking.

```
ABILITY / POSSIBILITY → WISH + COULD + VERB
```

> I wish I **could speak** English.

Y exactamente lo mismo con `If only`:

```
IF ONLY + PAST
IF ONLY + HAD + PP
IF ONLY + WOULD + VERB
IF ONLY + COULD + VERB
```

### Regla rápida

> **WISH + PAST** → quiero que el **presente** fuera diferente.  
> **WISH + PAST PERFECT** → quiero que el **pasado** hubiera sido diferente.  
> **WISH + WOULD** → quiero que algo/alguien **cambie**.  
> **WISH + COULD** → deseo tener una **habilidad o posibilidad**.
