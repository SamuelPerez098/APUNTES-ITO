# Modal Verbs

Los **modal verbs** son verbos auxiliares que expresan ideas como:

- habilidad
- posibilidad
- probabilidad
- permiso
- obligación
- necesidad
- consejo
- prohibición
- intención o disposición

### Structure

```
Subject + Modal + Verb (base form) + Complement
```

Ejemplos:

- She **can swim**.
- You **should study**.
- They **might arrive** later.
- He **must leave**.

> [!warning] Regla fundamental  
> Después de un modal siempre utilizamos el **verbo en forma base**.
> 
> ✅ She can **speak** English.
> 
> ❌ She can **speaks** English.
> 
> ❌ She can **to speak** English.

---

# 2. Principales Modal Verbs

|Modal|Uso principal|Significado aproximado|
|---|---|---|
|**can**|habilidad / posibilidad / permiso|poder|
|**could**|habilidad pasada / posibilidad / petición|podía / podría|
|**may**|posibilidad / permiso formal|puede / podría|
|**might**|posibilidad menos segura|podría / quizá|
|**must**|obligación / deducción|deber / tener que|
|**should**|consejo / expectativa|debería|
|**will**|futuro / voluntad / predicción|hará / va a|
|**would**|condicional / cortesía / hábito pasado|haría / solía|
|**shall**|propuesta / futuro formal|debería / hará|

---

# 3. CAN

### Uses

**Habilidad:**

> I **can speak** English.

**Posibilidad:**

> It **can happen**.

**Permiso:**

> You **can leave** now.

### Structure

```
Subject + can + Verb (base form)
```

### Negative

```
Subject + cannot/can't + Verb
```

> I **can't swim**.

### Question

```
Can + Subject + Verb?
```

> **Can you help** me?

---

# 4. COULD

### Uses

**Habilidad en el pasado:**

> I **could swim** when I was five.

**Posibilidad:**

> It **could rain** tomorrow.

**Petición cortés:**

> **Could you help** me?

### Structure

```
Subject + could + Verb (base form)
```

> [!info] Importante  
> `Could` no significa únicamente "can en pasado". También expresa **posibilidad** y **peticiones corteses**.

---

# 5. MAY

### Uses

**Posibilidad:**

> It **may rain** tomorrow.

**Permiso formal:**

> You **may leave** now.

### Structure

```
Subject + may + Verb (base form)
```

---

# 6. MIGHT

Expresa una **posibilidad**, normalmente menos segura que `may`.

```
Subject + might + Verb (base form)
```

> She **might come** later.

> He **might be** at home.

Una escala aproximada:

```
must → should → may → might
más seguro             menos seguro
```

No es una escala matemática exacta, pero sirve como referencia.

---

# 7. MUST

### Uses

**Obligación:**

> You **must wear** a seat belt.

**Deducción lógica fuerte:**

> She has been studying all day. She **must be** tired.

### Structure

```
Subject + must + Verb (base form)
```

### Negative

```
Subject + must not / mustn't + Verb
```

> You **mustn't smoke** here.

> [!warning] MUSTN'T  
> `Mustn't` significa **prohibición**.
> 
> **You mustn't leave.**
> 
> → No debes / tienes prohibido salir.

No significa simplemente "no tienes que".

---

# 8. SHOULD

### Uses

**Consejo:**

> You **should study** more.

**Expectativa:**

> The train **should arrive** soon.

### Structure

```
Subject + should + Verb (base form)
```

### Negative

```
Subject + should not / shouldn't + Verb
```

> You **shouldn't worry**.

---

# 9. WILL

Principalmente expresa futuro, predicciones, decisiones, promesas y voluntad.

```
Subject + will + Verb (base form)
```

> I **will study** tomorrow.

> She **will help** you.

### Negative

```
Subject + will not / won't + Verb
```

### Question

```
Will + Subject + Verb?
```

> **Will you come** tomorrow?

---

# 10. WOULD

Tiene varios usos importantes.

### Conditional

> I **would travel** if I had money.

### Polite request

> **Would you help** me?

### Preference

> I **would rather stay** home.

### Past habit

> When I was young, I **would play** soccer every day.

---

# 11. SHALL

Es menos común en inglés estadounidense moderno, pero puede aparecer en TOEFL.

Se utiliza principalmente para:

- sugerencias
- propuestas
- ofrecimientos
- lenguaje formal

### Example

> **Shall we go**?

→ ¿Vamos?

> **Shall I open** the window?

→ ¿Abro la ventana?

---

# 12. Modal Verbs "Secundarios"

Además de los modales principales, existen estructuras que funcionan de manera similar a los modales.

Los más importantes son:

|Semi-modal|Significado|
|---|---|
|**have to**|tener que|
|**need to**|necesitar|
|**be able to**|ser capaz de / poder|
|**be allowed to**|tener permitido|
|**be supposed to**|se supone que|
|**ought to**|debería|
|**had better**|sería mejor que|
|**used to**|solía|

Estos son especialmente importantes porque **no todos siguen exactamente las reglas de los modal verbs principales**.

---

# 13. HAVE TO

Expresa obligación o necesidad.

```
Subject + have/has to + Verb
```

> I **have to study**.

> She **has to work**.

### Past

```
Subject + had to + Verb
```

> I **had to leave**.

### Future

```
Subject + will have to + Verb
```

> I **will have to study**.

---

# 14. NEED TO

Expresa necesidad.

```
Subject + need to + Verb
```

> I **need to study**.

> She **needs to work**.

Puede utilizarse en diferentes tiempos:

> I **needed to study**.

> I **will need to study**.

---

# 15. BE ABLE TO

Significa **poder / ser capaz de**.

Es especialmente útil porque permite expresar `can` en tiempos donde `can` no puede utilizarse normalmente.

```
Subject + be able to + Verb
```

Examples:

> I **am able to swim**.

> I **was able to swim**.

> I **will be able to swim**.

> I **have been able to swim**.

### Comparison

> I **can swim**.

> I **will be able to swim**.

No:

> ❌ I will can swim.

---

# 16. BE ALLOWED TO

Significa **tener permitido**.

```
Subject + be allowed to + Verb
```

Examples:

> Students **are allowed to use** computers.

> Students **were allowed to leave**.

> Students **will be allowed to enter**.

---

# 17. BE SUPPOSED TO

Expresa algo que **se supone que debe ocurrir** o una expectativa/obligación.

```
Subject + be supposed to + Verb
```

Examples:

> You **are supposed to study**.

> He **was supposed to arrive** at 8.

> We **are supposed to finish** today.

---

# 18. OUGHT TO

Tiene un significado parecido a `should`.

```
Subject + ought to + Verb
```

> You **ought to study** more.

→ Deberías estudiar más.

Es menos frecuente que `should`, pero conviene reconocerlo.

---

# 19. HAD BETTER

Expresa un consejo fuerte o advertencia.

```
Subject + had better + Verb
```

> You **had better study**.

→ Más te vale estudiar / sería mejor que estudiaras.

### Negative

```
Subject + had better not + Verb
```

> You **had better not be** late.

> [!warning] No uses `to`
> 
> ❌ You had better **to study**.
> 
> ✅ You had better **study**.

---

# 20. Modal + BE

Los modales pueden combinarse con `be`.

```
Subject + Modal + be + Complement
```

Examples:

> She **may be** tired.

> He **must be** at home.

> They **could be** late.

Esto es muy importante para expresar **probabilidad/deducción**.

---

# 21. Modal + HAVE + Past Participle

Aquí entramos en los **modals in the past**.

### Structure

```
Subject + Modal + have + Past Participle
```

Se utiliza para hablar de posibilidades, deducciones, arrepentimientos o situaciones relacionadas con el pasado.

---

# 22. MUST HAVE + Past Participle

Expresa una **deducción fuerte sobre el pasado**.

```
Subject + must have + Past Participle
```

> She **must have forgotten**.

→ Debe de haberlo olvidado.

> He **must have been** tired.

→ Debía de haber estado cansado.

La idea es:

> Tengo evidencia y estoy casi seguro de que ocurrió.

---

# 23. MAY HAVE / MIGHT HAVE + Past Participle

Expresan una **posibilidad en el pasado**.

```
Subject + may/might have + Past Participle
```

> She **may have forgotten**.

→ Puede que lo haya olvidado.

> He **might have missed** the bus.

→ Quizá perdió el autobús.

### Diferencia

> He **must have forgotten**.

→ Estoy bastante seguro.

> He **might have forgotten**.

→ Es una posibilidad.

---

# 24. COULD HAVE + Past Participle

Puede expresar:

### Posibilidad pasada

> She **could have been** at home.

→ Podría haber estado en casa.

### Oportunidad que no se aprovechó

> You **could have told** me.

→ Podrías habérmelo dicho.

---

# 25. SHOULD HAVE + Past Participle

Expresa que algo **debió haberse hecho**, pero probablemente no ocurrió.

```
Subject + should have + Past Participle
```

> You **should have studied**.

→ Deberías haber estudiado.

> He **should have called** me.

→ Debería haberme llamado.

También puede expresar expectativa:

> The package **should have arrived** by now.

→ El paquete debería haber llegado ya.

---

# 26. SHOULDN'T HAVE + Past Participle

Expresa que algo **no debió hacerse**, pero se hizo.

```
Subject + shouldn't have + Past Participle
```

> You **shouldn't have said** that.

→ No deberías haber dicho eso.

> I **shouldn't have eaten** so much.

→ No debí haber comido tanto.

---

# 27. WOULD HAVE + Past Participle

Se utiliza principalmente en situaciones **condicionales del pasado**.

```
Subject + would have + Past Participle
```

> I **would have gone** if I had had time.

→ Habría ido si hubiera tenido tiempo.

Esto es fundamental para el **Third Conditional**.

---

# 28. CAN'T HAVE / COULDN'T HAVE + Past Participle

Expresa una **deducción negativa sobre el pasado**.

```
Subject + can't/couldn't have + Past Participle
```

> He **can't have forgotten**.

→ No puede haberlo olvidado.

> She **couldn't have done** it.

→ No pudo haberlo hecho.

La idea es:

> Estoy seguro de que eso **no ocurrió**.

---

# 29. Modal Perfect — Resumen

|Estructura|Significado|
|---|---|
|**must have + PP**|casi seguro que ocurrió|
|**may have + PP**|posiblemente ocurrió|
|**might have + PP**|quizá ocurrió|
|**could have + PP**|pudo haber ocurrido / pudo haberlo hecho|
|**should have + PP**|debería haber ocurrido/hecho|
|**shouldn't have + PP**|no debería haber ocurrido/hecho|
|**would have + PP**|habría ocurrido/hecho|
|**can't have + PP**|es imposible que haya ocurrido|
|**couldn't have + PP**|no pudo haber ocurrido|

`PP = Past Participle`
