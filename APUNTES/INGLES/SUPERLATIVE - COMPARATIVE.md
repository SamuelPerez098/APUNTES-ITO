

# Comparatives

Los **comparatives** se utilizan para comparar **dos personas, cosas o situaciones**.

### Structure

```
Subject + Verb + Comparative + than + Object
```

> John is **taller than** Peter.

> This book is **more interesting than** that one.

---

# 2. Adjetivos cortos → `-ER`

Generalmente, los adjetivos de **una sílaba** forman el comparativo agregando `-er`.

|Adjective|Comparative|Example|
|---|---|---|
|tall|**taller**|taller than|
|fast|**faster**|faster than|
|small|**smaller**|smaller than|
|old|**older**|older than|
|cheap|**cheaper**|cheaper than|

```
Adjective + -er + than
```

---

# 3. Adjetivos que terminan en `-E`

Solo agregamos `-r`.

|Adjective|Comparative|
|---|---|
|large|**larger**|
|nice|**nicer**|
|safe|**safer**|
|wide|**wider**|

```
Adjective + -r
```

---

# 4. Consonante + vocal + consonante

Cuando un adjetivo corto termina en:

```
Consonant + Vowel + Consonant
```

normalmente duplicamos la última consonante.

|Adjective|Comparative|
|---|---|
|big|**bigger**|
|hot|**hotter**|
|thin|**thinner**|
|sad|**sadder**|

> big → bigger  
> hot → hotter

---

# 5. Adjetivos terminados en `-Y`

Si termina en consonante + `y`:

```
-y → -ier
```

|Adjective|Comparative|
|---|---|
|happy|**happier**|
|easy|**easier**|
|busy|**busier**|
|funny|**funnier**|
|happy|**happier**|

> happy → happ**ier**

Pero si hay una vocal antes de `y`, normalmente solo agregamos `-er`:

> gray → grayer

---

# 6. Adjetivos largos → MORE

Con adjetivos de **dos o más sílabas**, normalmente utilizamos `more`.

### Structure

```
Subject + more + Adjective + than + Object
```

|Adjective|Comparative|
|---|---|
|expensive|**more expensive**|
|interesting|**more interesting**|
|beautiful|**more beautiful**|
|difficult|**more difficult**|
|important|**more important**|

> This exam is **more difficult than** the previous one.

> [!warning] No mezcles `more` con `-er`
> 
> ❌ more taller
> 
> ❌ expensiver
> 
> ✅ taller
> 
> ✅ more expensive

---

# 7. Irregular Comparatives

Estos debes memorizarlos.

|Adjective|Comparative|Español|
|---|---|---|
|good|**better**|mejor|
|bad|**worse**|peor|
|far|**farther / further**|más lejos|
|little|**less**|menos|
|much|**more**|más|
|many|**more**|más|

Ejemplos:

> This book is **better than** that one.

> Today's weather is **worse than** yesterday's.

---

# 8. Comparación de igualdad

Para decir que dos cosas tienen **el mismo grado** utilizamos:

### Structure

```
as + Adjective + as
```

> John is **as tall as** Peter.

→ John es tan alto como Peter.

### Negativo

```
not as + Adjective + as
```

> John is **not as tall as** Peter.

→ John no es tan alto como Peter.

---

# 9. Comparatives con `less`

También podemos comparar utilizando `less`.

### Structure

```
less + Adjective + than
```

> This exercise is **less difficult than** the previous one.

→ Este ejercicio es menos difícil que el anterior.

---

# 10. Superlatives

Los **superlatives** se utilizan para indicar que alguien o algo tiene el **grado más alto o más bajo dentro de un grupo**.

Normalmente hablamos de **tres o más elementos**.

### Structure

```
Subject + Verb + the + Superlative + in/of + Group
```

> John is **the tallest student** in the class.

---

# 11. Adjetivos cortos → `-EST`

### Structure

```
the + Adjective + -est
```

|Adjective|Superlative|
|---|---|
|tall|**the tallest**|
|fast|**the fastest**|
|small|**the smallest**|
|old|**the oldest**|
|cheap|**the cheapest**|

---

# 12. Adjetivos terminados en `-E`

Solo agregamos `-st`.

|Adjective|Superlative|
|---|---|
|large|**the largest**|
|nice|**the nicest**|
|safe|**the safest**|
|wide|**the widest**|

---

# 13. Consonante + vocal + consonante

Duplicamos la última consonante.

|Adjective|Superlative|
|---|---|
|big|**the biggest**|
|hot|**the hottest**|
|thin|**the thinnest**|
|sad|**the saddest**|

---

# 14. Adjetivos terminados en `-Y`

```
-y → -iest
```

|Adjective|Superlative|
|---|---|
|happy|**the happiest**|
|easy|**the easiest**|
|busy|**the busiest**|
|funny|**the funniest**|

---

# 15. Adjetivos largos → MOST

Con adjetivos largos utilizamos `most`.

### Structure

```
the + most + Adjective
```

|Adjective|Superlative|
|---|---|
|expensive|**the most expensive**|
|interesting|**the most interesting**|
|beautiful|**the most beautiful**|
|difficult|**the most difficult**|
|important|**the most important**|

> This is **the most difficult** question.

---

# 16. Superlativos irregulares

|Adjective|Comparative|Superlative|
|---|---|---|
|good|better|**the best**|
|bad|worse|**the worst**|
|far|farther/further|**the farthest/furthest**|
|little|less|**the least**|
|much/many|more|**the most**|

Estos son **muy importantes para memorizar**.

---

# 17. `THE` con superlativos

Normalmente utilizamos **the** antes del superlativo.

```
the + Superlative
```

> She is **the tallest** student.

> This is **the most expensive** car.

> He is **the best** player.

> [!warning] Error frecuente
> 
> ❌ She is tallest student.
> 
> ✅ She is **the tallest student**.

---

# 18. Comparative vs Superlative

|Comparative|Superlative|
|---|---|
|Compara **2**|Compara **3 o más**|
|`-er` / `more`|`-est` / `most`|
|normalmente `than`|normalmente `the`|
|taller than|the tallest|
|more expensive than|the most expensive|

### Example

**Comparative:**

> John is **taller than** Peter.

→ 2 personas.

**Superlative:**

> John is **the tallest** student in the class.

→ John + todos los demás estudiantes.

---

# 19. Comparativos con cantidades

También puedes comparar cantidades.

### Countable nouns

```
more + Plural Countable Noun + than
```

> I have **more books than** you.

### Uncountable nouns

```
more + Uncountable Noun + than
```

> I have **more money than** you.

### Less

```
less + Uncountable Noun + than
```

> I have **less money than** you.

### Fewer

Para sustantivos contables:

```
fewer + Plural Countable Noun + than
```

> I have **fewer books than** you.

Esto conecta directamente con **countable / uncountable nouns y quantifiers**.

---

# 20. Intensificadores de comparativos

Podemos aumentar o disminuir la intensidad del comparativo.

|Intensifier|Example|
|---|---|
|**much**|much better|
|**far**|far more expensive|
|**a lot**|a lot easier|
|**a little**|a little cheaper|
|**slightly**|slightly faster|
|**even**|even better|

Ejemplos:

> This exam is **much harder than** the previous one.

> This computer is **slightly faster than** mine.

> The new version is **far more expensive than** the old one.

---

# 21. Comparativo progresivo

Se utiliza para indicar que algo **continúa aumentando o disminuyendo**.

### Short adjectives

```
Comparative + and + Comparative
```

> The weather is getting **colder and colder**.

### Long adjectives

```
more and more + Adjective
```

> English is becoming **more and more important**.

---

# 22. The more..., the more...

Estructura avanzada muy útil para B2-C1.

### Structure

```
The + Comparative + Subject + Verb,
the + Comparative + Subject + Verb.
```

> **The more you study, the better you become.**

→ Cuanto más estudias, mejor te vuelves.

Otros ejemplos:

> **The more expensive** it is, **the better** it should be.

> **The harder** you work, **the more successful** you become.

---

# 23. Resumen de reglas

|Tipo de adjetivo|Comparative|Superlative|
|---|---|---|
|Corto|`-er`|`-est`|
|Termina en `-e`|`-r`|`-st`|
|CVC|duplica consonante + `-er`|duplica + `-est`|
|consonante + `y`|`-ier`|`-iest`|
|Largo|`more + adj.`|`the most + adj.`|
|Irregular|memorizar|memorizar|
