

# BY vs UNTIL

### BY

Significa **"a más tardar"** o indica una fecha límite.

```
BY + deadline
```

> Finish the report **by Friday**.

→ Termina el reporte **a más tardar el viernes**.

### UNTIL

Indica que una situación **continúa hasta un momento determinado**.

```
UNTIL + endpoint
```

> I will stay here **until Friday**.

→ Me quedaré aquí **hasta el viernes**.

### Diferencia

> I need the report **by Friday**.

→ Debe estar terminado antes o como máximo el viernes.

> I will work **until Friday**.

→ Continuaré trabajando hasta el viernes.


# BETWEEN vs AMONG

### BETWEEN

Normalmente se utiliza para relaciones entre **dos elementos**, aunque también puede utilizarse para más de dos cuando los elementos están claramente diferenciados.

> The restaurant is **between** the bank and the hotel.

### AMONG

Se utiliza cuando algo está dentro de un **grupo**.

> She was sitting **among** her friends.

```
BETWEEN → elementos diferenciados
AMONG → grupo
```

#  BY vs WITH

### BY

Puede indicar **quién realiza una acción**, especialmente en Passive Voice.

> The book was written **by** Orwell.

También puede indicar medio o método:

> I traveled **by** train.

### WITH

Puede indicar la **herramienta o instrumento** utilizado.

> He cut the paper **with** a knife.

```
BY → agente / medio de transporte
WITH → instrumento
```

# Prepositions después de verbos

Algunos verbos requieren determinadas preposiciones.

|Verb|Preposition|Example|
|---|---|---|
|depend|**on**|depend on|
|listen|**to**|listen to|
|belong|**to**|belong to|
|wait|**for**|wait for|
|look|**at**|look at|
|look|**for**|look for|
|look|**after**|look after|
|participate|**in**|participate in|
|succeed|**in**|succeed in|
|consist|**of**|consist of|
|suffer|**from**|suffer from|
|agree|**with**|agree with someone|
|apologize|**for**|apologize for|
|believe|**in**|believe in|

Estas combinaciones conviene memorizarlas como **chunks**, no traducir palabra por palabra.

# Prepositions después de adjetivos

También existen combinaciones frecuentes:

|Adjective|Preposition|Example|
|---|---|---|
|afraid|**of**|afraid of spiders|
|interested|**in**|interested in science|
|good|**at**|good at English|
|bad|**at**|bad at math|
|famous|**for**|famous for its food|
|responsible|**for**|responsible for the project|
|similar|**to**|similar to mine|
|different|**from**|different from yours|
|proud|**of**|proud of you|
|capable|**of**|capable of doing it|
|dependent|**on**|dependent on others|
|familiar|**with**|familiar with the system|

# Preposition + Gerund

Una regla muy importante:

Cuando una preposición va seguida de un verbo, normalmente utilizamos **-ing**.

```
PREPOSITION + VERB-ING
```

> She is interested **in learning** English.

> He left without **saying** goodbye.

> They talked about **moving** abroad.

No:

> ❌ interested in **learn**

> ❌ without **say**

#  `TO como preposición

Cuidado: `to` no siempre introduce infinitivo.

### Infinitive

```
TO + VERB
```

> I want **to study**.

### Preposition

```
TO + NOUN / GERUND
```

> I look forward **to seeing** you.

> She is accustomed **to working** late.
