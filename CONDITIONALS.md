
# 1. Zero Conditional

Se utiliza para hablar de **hechos generales, verdades, reglas, hábitos o situaciones que siempre ocurren cuando se cumple una condición**.

### Structure

```
If + Present Simple, Present Simple
```

También:

```
Present Simple + if + Present Simple
```

### Examples

- If you **heat** water, it **boils**.
- If I **drink** coffee at night, I **can't sleep**.
- If it **rains**, the ground **gets** wet.

### Idea clave

> **Siempre que A ocurre → B ocurre.**

```
IF + Present → Present
```

---

# 2. First Conditional

Se utiliza para situaciones **reales o posibles en el futuro**.

La condición tiene una posibilidad razonable de cumplirse.

### Structure

```
If + Present Simple, will + Verb (base form)
```

### Examples

- If I **study**, I **will pass** the exam.
- If it **rains**, we **will stay** home.
- If she **works** hard, she **will succeed**.

### Idea clave

> **Si A ocurre → probablemente B ocurrirá.**

```
IF + Present → WILL + Verb
```

> [!warning] Regla muy importante  
> Después de `if` **NO utilizamos normalmente `will`** en el First Conditional.
> 
> ❌ If I **will study**, I will pass.
> 
> ✅ If I **study**, I will pass.

---

# 3. Second Conditional

Se utiliza para situaciones **hipotéticas, improbables o imaginarias en el presente o futuro**.

### Structure

```
If + Past Simple, would + Verb (base form)
```

### Examples

- If I **had** more money, I **would travel**.
- If she **studied** more, she **would pass**.
- If I **were** you, I **would study** harder.

### Idea clave

> **Si A ocurriera → B ocurriría.**

```
IF + Past → WOULD + Verb
```

> [!info] WERE  
> En situaciones hipotéticas, especialmente en inglés formal, usamos **were** con todas las personas:
> 
> **If I were...**
> 
> **If he were...**
> 
> **If she were...**
> 
> La expresión **If I were you...** es especialmente importante.

---

# 4. Third Conditional

El **Third Conditional** habla de una situación **hipotética en el pasado**.

La condición **no ocurrió**, por lo que el resultado tampoco ocurrió.

### Structure

```
If + Past Perfect, would have + Past Participle
```

### Examples

- If I **had studied**, I **would have passed** the exam.
- If she **had left** earlier, she **would have arrived** on time.
- If they **had listened**, they **would have avoided** the problem.

### Idea clave

> **Si A hubiera ocurrido → B habría ocurrido.**

```
IF + HAD + PP → WOULD HAVE + PP
```

`PP = Past Participle`

---

# 5. La clave para memorizar los 4

Esta es la parte que te recomiendo memorizar **como una escalera**:

|Conditional|IF clause|Result clause|Idea|
|---|---|---|---|
|**Zero**|Present|Present|Siempre ocurre|
|**First**|Present|Will + Verb|Posible futuro|
|**Second**|Past|Would + Verb|Hipotético|
|**Third**|Had + PP|Would have + PP|Hipotético pasado|

### Fórmula rápida

```
ZERO
IF + PRESENT → PRESENT
```

```
FIRST
IF + PRESENT → WILL + VERB
```

```
SECOND
IF + PAST → WOULD + VERB
```

```
THIRD
IF + HAD + PP → WOULD HAVE + PP
```

# 6. Truco de memorización

Observa cómo cambia únicamente el **tiempo verbal**:

### Zero

```
IF + PRESENT
        ↓
   PRESENT
```

> If I **study**, I **learn**.

### First

```
IF + PRESENT
        ↓
   WILL + VERB
```

> If I **study**, I **will pass**.

### Second

```
IF + PAST
        ↓
   WOULD + VERB
```

> If I **studied**, I **would pass**.

### Third

```
IF + HAD + PP
        ↓
 WOULD HAVE + PP
```

> If I **had studied**, I **would have passed**.

La progresión que debes recordar es:

```
PRESENT → PRESENT
PRESENT → WILL
PAST → WOULD
HAD + PP → WOULD HAVE + PP
```

---

# 7. Los cuatro con el mismo ejemplo

Esta es probablemente la mejor manera de diferenciarlos:

### ZERO — hecho general

> If I **study**, I **learn**.

→ Cuando estudio, aprendo.

### FIRST — posibilidad futura

> If I **study**, I **will pass**.

→ Si estudio, aprobaré.

### SECOND — situación hipotética

> If I **studied**, I **would pass**.

→ Si estudiara, aprobaría.

### THIRD — pasado imposible de cambiar

> If I **had studied**, I **would have passed**.

→ Si hubiera estudiado, habría aprobado.

# 8. Negative Conditionals

Podemos utilizar `not` en cualquiera de las partes.

### Zero

```
If + Subject + don't/doesn't + Verb, ...
```

> If you **don't water** plants, they **die**.

### First

```
If + Subject + don't/doesn't + Verb, Subject + will + Verb
```

> If I **don't study**, I **will fail**.

### Second

```
If + Subject + didn't + Verb, Subject + would + Verb
```

> If I **didn't work**, I **would travel** more.

### Third

```
If + Subject + hadn't + PP, Subject + would have + PP
```

> If I **hadn't studied**, I **would have failed**.

---

# 9. Could / Might en los Conditionals

No siempre tenemos que utilizar `will` o `would`.

### First Conditional

```
If + Present → may/might/can + Verb
```

> If it rains, we **might stay** home.

### Second Conditional

```
If + Past → could/might + Verb
```

> If I had more money, I **could travel**.

> If she studied harder, she **might pass**.

### Third Conditional

```
If + Past Perfect → could/might have + PP
```

> If I had studied, I **could have passed**.

> If she had left earlier, she **might have arrived** on time.

---

# 10. Unless

`Unless` significa aproximadamente **"a menos que"** y equivale a:

```
unless = if ... not
```

### Example

> **Unless you study**, you will fail.

Equivale a:

> **If you don't study**, you will fail.

### Structure

```
Unless + Present Simple, will + Verb
```

> Unless it **rains**, we **will go**.

> [!warning] No hagas doble negativo
> 
> ❌ Unless you **don't study**, you will fail.
> 
> ✅ Unless you **study**, you will fail.
> 
> `unless` ya incorpora la idea negativa.

---

# 11. If + Imperative

También podemos utilizar `if` con una orden o instrucción.

```
If + Present Simple, Imperative
```

> If you **see John**, **tell him** to call me.

> If you **feel tired**, **take a break**.
