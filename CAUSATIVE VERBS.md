
# Causative Verbs

Los principales son:

```
MAKE
HAVE
GET
LET
```

---

## 2.1 MAKE

Significa **obligar / hacer que alguien haga algo**.

```
MAKE + PERSON + VERB
```

> The teacher **made me study**.

No utilizamos `to`.

❌ The teacher made me **to study**.

✅ The teacher made me **study**.

---

## 2.2 HAVE

Puede significar **hacer que alguien realice algo**.

```
HAVE + PERSON + VERB
```

> I **had John repair** my computer.

También puede utilizarse para contratar/encargar un servicio:

```
HAVE + OBJECT + PAST PARTICIPLE
```

> I **had my computer repaired**.

---

## 2.3 GET

Puede significar **conseguir/persuadir a alguien para que haga algo**.

```
GET + PERSON + TO + VERB
```

> I **got John to repair** my computer.

También:

```
GET + OBJECT + PAST PARTICIPLE
```

> I **got my computer repaired**.

---

## 2.4 LET

Significa **permitir/dejar**.

```
LET + PERSON + VERB
```

> My parents **let me go**.

No utilizamos `to`.

❌ They let me **to go**.

✅ They let me **go**.

---

# 3. Causative Verbs — Tabla esencial

|Verb|Structure|Significado|
|---|---|---|
|**make**|make + person + verb|obligar|
|**have**|have + person + verb|hacer/pedir|
|**get**|get + person + to + verb|persuadir/conseguir|
|**let**|let + person + verb|permitir|
|**have**|have + object + PP|encargar servicio|
|**get**|get + object + PP|conseguir servicio|

### Memoriza esta secuencia:

```
MAKE + PERSON + VERB
HAVE + PERSON + VERB
GET  + PERSON + TO + VERB
LET  + PERSON + VERB
```
