
# .Discourse Markers

Los **Discourse Markers** son palabras o expresiones que indican **cómo se relaciona una idea con la anterior**.

Pueden indicar:

- contraste
- causa
- consecuencia
- adición
- ejemplo
- orden
- conclusión
- reformulación
- énfasis

Son muy importantes para **Reading y Listening**, porque te ayudan a anticipar qué viene después.

---

## 1.1 Addition — Adición

Se utilizan para agregar información.

|Discourse Marker|Significado|
|---|---|
|**and**|y|
|**also**|también|
|**too**|también|
|**as well**|también|
|**in addition**|además|
|**additionally**|adicionalmente|
|**furthermore**|además|
|**moreover**|además|
|**besides**|además|

### Examples

> The course is difficult. **Moreover**, it is very demanding.

> She speaks English. **She also** speaks French.

### Diferencia importante

**Furthermore / Moreover** suelen ser más formales.

```
also
      ↓
in addition
      ↓
furthermore / moreover
```

# 1.2 Contrast — Contraste

Indican que la segunda idea contrasta con la primera.

|Marker|Significado|
|---|---|
|**but**|pero|
|**however**|sin embargo|
|**although**|aunque|
|**though**|aunque|
|**even though**|aunque / a pesar de que|
|**nevertheless**|sin embargo|
|**nonetheless**|no obstante|
|**in contrast**|en contraste|
|**on the other hand**|por otro lado|
|**whereas**|mientras que|
|**while**|mientras que|

### Examples

> The exam was difficult. **However**, I passed.

> **Although** the exam was difficult, I passed.

> The north is cold, **whereas** the south is warm.

---

# 1.3 Cause / Reason — Causa

Explican **por qué ocurre algo**.

|Marker|Significado|
|---|---|
|**because**|porque|
|**since**|ya que / puesto que|
|**as**|ya que|
|**because of**|debido a|
|**due to**|debido a|
|**owing to**|debido a|

### Example

> The game was canceled **because** it rained.

> The game was canceled **because of** the rain.

### Regla importante

```
BECAUSE + CLAUSE
```

> because **it rained**

```
BECAUSE OF + NOUN
```

> because of **the rain**

Lo mismo ocurre generalmente con:

```
DUE TO + NOUN
OWING TO + NOUN
```

---

# 1.4 Result / Consequence — Consecuencia

Indican el **resultado** de algo.

|Marker|Significado|
|---|---|
|**so**|así que|
|**therefore**|por lo tanto|
|**thus**|por lo tanto|
|**hence**|de ahí / por lo tanto|
|**consequently**|consecuentemente|
|**as a result**|como resultado|
|**for this reason**|por esta razón|

### Example

> It was raining. **Therefore**, we stayed home.

> He studied hard. **As a result**, he passed the exam.

---

# 1.5 Example — Ejemplificación

|Marker|Significado|
|---|---|
|**for example**|por ejemplo|
|**for instance**|por ejemplo|
|**such as**|como / tales como|
|**including**|incluyendo|

### Examples

> Many countries, **such as** Mexico and Canada, use this system.

> Some sports, **for example**, soccer and tennis, are very popular.

### Diferencia

```
FOR EXAMPLE + CLAUSE / EXAMPLE
```

> Many sports are popular. **For example, soccer is...**

```
SUCH AS + NOUN / NOUN PHRASE
```

> Sports **such as soccer and tennis** are popular.

---

# 1.6 Sequence — Orden

Indican el orden de los acontecimientos o argumentos.

|Marker|Significado|
|---|---|
|**first / firstly**|primero|
|**first of all**|antes que nada|
|**second / secondly**|segundo|
|**then**|entonces / después|
|**next**|después|
|**after that**|después de eso|
|**finally**|finalmente|
|**lastly**|por último|

### Example

> **First**, collect the data.  
> **Then**, analyze it.  
> **Finally**, write the report.

---

# 1.7 Conclusion — Conclusión

|Marker|Significado|
|---|---|
|**in conclusion**|en conclusión|
|**to conclude**|para concluir|
|**in summary**|en resumen|
|**to summarize**|para resumir|
|**overall**|en general|
|**in short**|en pocas palabras|

### Example

> **In conclusion**, the experiment was successful.

---

# 1.8 Reformulation — Reformulación

Sirven para decir la misma idea de otra manera.

|Marker|Significado|
|---|---|
|**in other words**|en otras palabras|
|**that is**|es decir|
|**that is to say**|es decir|
|**namely**|concretamente / a saber|
|**more precisely**|más precisamente|

### Example

> The project was unsuccessful. **In other words**, it failed.

---

# 1.9 Emphasis — Énfasis

|Marker|Significado|
|---|---|
|**indeed**|en efecto|
|**in fact**|de hecho|
|**especially**|especialmente|
|**particularly**|particularmente|
|**above all**|sobre todo|
|**most importantly**|lo más importante|

### Example

> The exam was difficult. **In fact**, most students failed.
