
# Passive Voice

La **Passive Voice (voz pasiva)** se utiliza cuando queremos destacar la **acción o el objeto que recibe la acción**, en lugar de quién la realiza.

### Active

> The teacher **explains** the lesson.

### Passive

> The lesson **is explained** by the teacher.

---

# 2. Estructura principal

La regla más importante es:

```
Subject + BE + Past Participle (PP) + Complement
```

El verbo **BE** cambia dependiendo del tiempo verbal, pero el verbo principal siempre pasa a **Past Participle**.

```
BE + PP
```

> The car **was repaired**.

> The documents **have been sent**.

> The house **will be built**.

---

# 3. Cómo convertir Active → Passive

### Active

```
Subject + Verb + Object
```

> The company **built** the house.

### Passive

```
Object + BE + Past Participle + (by + Subject)
```

> The house **was built** by the company.

### Regla rápida

```
ACTIVE:
Someone → does → something

PASSIVE:
Something → is done → (by someone)
```

---

# 4. Passive en los principales tiempos

Esta es la tabla que más te recomiendo memorizar para el TOEFL:

|Tense|Active|Passive|
|---|---|---|
|**Present Simple**|writes|**is written**|
|**Present Continuous**|is writing|**is being written**|
|**Past Simple**|wrote|**was written**|
|**Past Continuous**|was writing|**was being written**|
|**Present Perfect**|has written|**has been written**|
|**Past Perfect**|had written|**had been written**|
|**Future with will**|will write|**will be written**|
|**Going to**|is going to write|**is going to be written**|
|**Modal**|can write|**can be written**|

La estructura que debes detectar es:

```
BE + PAST PARTICIPLE
```

---

# 5. Present Simple Passive

### Structure

```
Subject + am/is/are + Past Participle
```

### Examples

> English **is spoken** worldwide.

> Cars **are produced** in this factory.

> The room **is cleaned** every day.

### Active

> People **speak** English worldwide.

### Passive

> English **is spoken** worldwide.

---

# 6. Present Continuous Passive

### Structure

```
Subject + am/is/are + being + Past Participle
```

> The house **is being painted**.

> The cars **are being repaired**.

### Idea clave

```
Present Continuous:
BE + ING

Passive:
BE + BEING + PP
```

---

# 7. Past Simple Passive

### Structure

```
Subject + was/were + Past Participle
```

> The building **was constructed** in 1990.

> The documents **were sent** yesterday.

### Active

> They **built** the building in 1990.

### Passive

> The building **was built** in 1990.

---

# 8. Past Continuous Passive

### Structure

```
Subject + was/were + being + Past Participle
```

> The house **was being repaired** when I arrived.

> The cars **were being washed**.

---

# 9. Present Perfect Passive

### Structure

```
Subject + have/has + been + Past Participle
```

> The work **has been completed**.

> The documents **have been sent**.

### Compara

Active:

> They **have completed** the work.

Passive:

> The work **has been completed**.

---

# 10. Past Perfect Passive

### Structure

```
Subject + had + been + Past Participle
```

> The work **had been completed** before we arrived.

Active:

> They **had completed** the work.

Passive:

> The work **had been completed**.

---

# 11. Future Passive — WILL

### Structure

```
Subject + will + be + Past Participle
```

> The project **will be completed** next year.

> The results **will be announced** tomorrow.

### Regla

```
WILL + BE + PP
```

---

# 12. Going to — Passive

### Structure

```
Subject + am/is/are + going to + be + Past Participle
```

> The building **is going to be demolished**.

> The project **is going to be completed** soon.

### Regla

```
GOING TO + BE + PP
```

---

# 13. Passive con Modal Verbs

Los modales también pueden utilizarse en voz pasiva.

### Structure

```
Subject + Modal + be + Past Participle
```

> The problem **can be solved**.

> The rules **must be followed**.

> The work **should be completed**.

> The documents **may be required**.

### Regla fundamental

```
MODAL + BE + PP
```

---

# 14. Modal Perfect Passive

Para B2-C1, esta estructura es importante.

### Structure

```
Subject + Modal + have been + Past Participle
```

> The mistake **could have been avoided**.

> The problem **should have been solved**.

> The documents **must have been lost**.

### Memoriza:

```
Modal + HAVE + BEEN + PP
```

---

# 15. `BY`

Utilizamos **by + agent** para indicar quién realizó la acción.

> The book was written **by George Orwell**.

> The building was designed **by an architect**.

Pero muchas veces **no necesitamos mencionar quién realizó la acción**.

> The window was broken.

No necesitamos decir quién la rompió.

### Regla práctica

```
by + person/thing that performs the action
```

---

# 16. Cuándo usar Passive Voice

La voz pasiva es especialmente común cuando:

### 1. No sabemos quién hizo la acción

> My car **was stolen**.

No sabemos quién la robó.

### 2. No importa quién hizo la acción

> The road **was closed**.

### 3. La acción es más importante que la persona

> The experiment **was conducted** in 2025.

### 4. Lenguaje académico/científico

> The samples **were analyzed**.

> The results **were compared**.

Esto es especialmente importante para el **TOEFL**, porque la voz pasiva aparece mucho en textos académicos.

---

# 17. Passive Questions

### Present Simple

```
Is/Are + Subject + Past Participle?
```

> **Is English spoken** here?

### Past Simple

```
Was/Were + Subject + Past Participle?
```

> **Was the building constructed** in 1990?

### Present Perfect

```
Has/Have + Subject + been + Past Participle?
```

> **Has the work been completed?**

### Future

```
Will + Subject + be + Past Participle?
```

> **Will the project be completed** soon?

---

# 18. Passive Negatives

Simplemente colocamos `not` después del auxiliar.

### Present

```
Subject + am/is/are + not + PP
```

> The room **isn't cleaned** every day.

### Past

```
Subject + was/were + not + PP
```

> The house **wasn't built** in 1990.

### Perfect

```
Subject + have/has + not + been + PP
```

> The work **hasn't been completed**.

### Future

```
Subject + will + not + be + PP
```

> The project **won't be completed** today.

---

# 19. Verbos con dos objetos

Algunos verbos pueden tener dos objetos, como:

- give
- send
- tell
- offer
- show
- teach
- lend

### Active

> They **gave John a book**.

Podemos formar:

> John **was given a book**.

o:

> A book **was given to John**.

Esto es bastante útil para reconocer estructuras en preguntas de **TOEFL Structure**.

---

# 20. Passive con `get`

En inglés informal también podemos utilizar `get` en lugar de `be`.

```
Subject + get + Past Participle
```

> He **got injured**.

> She **got married**.

> My phone **got damaged**.

Es menos formal que `be + PP`.

Para TOEFL, la estructura principal que debes reconocer es:

```
BE + PAST PARTICIPLE
```

---

# 21. La fórmula para memorizar todos los tiempos

En lugar de memorizar cada pasiva como una estructura completamente diferente, piensa:

> **Mantén el tiempo verbal en BE + convierte el verbo principal a Past Participle.**

### Present Simple

```
am/is/are + PP
```

### Present Continuous

```
am/is/are + being + PP
```

### Past Simple

```
was/were + PP
```

### Past Continuous

```
was/were + being + PP
```

### Present Perfect

```
have/has + been + PP
```

### Past Perfect

```
had + been + PP
```

### Future

```
will + be + PP
```

### Modal

```
modal + be + PP
```

### Modal Perfect

```
modal + have been + PP
```
