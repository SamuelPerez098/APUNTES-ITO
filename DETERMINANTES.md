

# Determiners

Los **determiners (determinantes)** son palabras que aparecen normalmente **antes de un sustantivo** y ayudan a indicar si hablamos de algo específico, general, cantidad, posesión, etc.

### Structure

```
Determiner + Noun
```

Ejemplos:

- **the** book
- **a** book
- **my** book
- **this** book
- **some** books
- **every** student

### Main Determiners

|Tipo|Determiners|Ejemplo|Significado|
|---|---|---|---|
|Articles|a, an, the|**the book**|el libro|
|Demonstratives|this, that, these, those|**this book**|este libro|
|Possessives|my, your, his, her, its, our, their|**my book**|mi libro|
|Quantifiers|some, any, much, many, few, little|**some books**|algunos libros|
|Distributives|each, every, either, neither|**each student**|cada estudiante|
|Numbers|one, two, three...|**two books**|dos libros|
|Interrogatives|which, what, whose|**which book?**|¿qué libro?|
|Negative|no|**no money**|nada de dinero|
|Universal|all, both|**all students**|todos los estudiantes|

> [!info] Importante  
> Muchos determinantes **no pueden combinarse libremente**.
> 
> Por ejemplo:
> 
> ✅ **my book**
> 
> ❌ **the my book**
> 
> Pero algunos sí pueden aparecer juntos:
> 
> ✅ **all my books**
> 
> ✅ **both these books**
> 
> Esto se vuelve importante en niveles B2-C1.

# 2. Articles

Los artículos son uno de los grupos principales de determinantes.

|Article|Uso|Ejemplo|
|---|---|---|
|**a**|singular contable, sonido consonántico|a car|
|**an**|singular contable, sonido vocálico|an apple|
|**the**|algo específico/definido|the car|
|**Ø**|sin artículo|Cars are useful.|

### A / AN

```
a/an + Singular Countable Noun
```

- a student
- a university
- an apple
- an hour

> [!warning] El criterio es el sonido, no necesariamente la letra.
> 
> **a university** → /juː/ → sonido consonántico
> 
> **an hour** → /aʊ/ → sonido vocálico

---

# 3. THE

### Use

`The` indica que el sustantivo es **definido o específico**.

```
the + Noun
```

Ejemplos:

- **the book** on the table
- **the students** in my class
- **the information** you gave me

También puede utilizarse con sustantivos singulares, plurales e incontables.

|Tipo|Ejemplo|
|---|---|
|Singular countable|the student|
|Plural countable|the students|
|Uncountable|the information|

---

# 4. Zero Article

A veces no utilizamos ningún artículo.

Esto ocurre frecuentemente cuando hablamos de algo **en general**.

### Examples

- **Students** need education.
- **Dogs** are intelligent animals.
- **Water** is essential.
- **Information** is important.

Compara:

> **Students** need education.

→ estudiantes en general.

> **The students** need education.

→ estudiantes específicos.

---

# 5. Possessive Determiners

Los **possessive determiners** indican posesión o relación.

### Table

|Subject Pronoun|Possessive Determiner|Example|
|---|---|---|
|I|**my**|my book|
|you|**your**|your car|
|he|**his**|his house|
|she|**her**|her phone|
|it|**its**|its color|
|we|**our**|our school|
|they|**their**|their teacher|

### Structure

```
Possessive Determiner + Noun
```

Examples:

- **my computer**
- **your friend**
- **his brother**
- **her mother**
- **its name**
- **our house**
- **their children**

> [!warning] Importante  
> Los possessive determiners **necesitan un sustantivo después**.
> 
> ✅ This is **my book**.
> 
> ❌ This is **my**.

---

# 6. Possessive Pronouns

No debes confundirlos con los **possessive determiners**.

Los **possessive pronouns** sustituyen al sustantivo y **no llevan un sustantivo después**.

|Subject|Possessive Determiner|Possessive Pronoun|
|---|---|---|
|I|my|**mine**|
|you|your|**yours**|
|he|his|**his**|
|she|her|**hers**|
|it|its*|—|
|we|our|**ours**|
|they|their|**theirs**|

### Comparison

**Possessive Determiner:**

```
My + Noun
```

> This is **my book**.

**Possessive Pronoun:**

```
Possessive Pronoun
```

> This book is **mine**.

Otro ejemplo:

> That is **her car**.

> That car is **hers**.

> These are **their books**.

> These books are **theirs**.

> [!warning] Error frecuente
> 
> ❌ This book is my.
> 
> ✅ This book is mine.
> 
> ❌ This is mine book.
> 
> ✅ This is my book.

# 7. Demonstrative Determiners

Los **demonstratives** señalan personas, objetos o ideas según **distancia** y **número**.

||Singular|Plural|
|---|---|---|
|Cerca|**this**|**these**|
|Lejos|**that**|**those**|

### Structure

```
Demonstrative + Noun
```

### Examples

- **this book**
- **these books**
- **that car**
- **those cars**

---

# 8. THIS

Se utiliza para:

- singular
- algo cercano
- una situación o idea actual

```
This + Singular Noun
```

Examples:

- **this book**
- **this student**
- **this problem**
- **this information**

> **This book** is interesting.

---

# 9. THESE

Se utiliza para:

- plural
- cosas/personas cercanas

```
These + Plural Noun
```

Examples:

- **these books**
- **these students**
- **these problems**
- **these ideas**

> **These books** are expensive.

---

# 10. THAT

Se utiliza para:

- singular
- algo relativamente lejano
- algo mencionado anteriormente

```
That + Singular Noun
```

Examples:

- **that car**
- **that house**
- **that student**
- **that idea**

> **That car** is expensive.

---

# 11. THOSE

Se utiliza para:

- plural
- cosas/personas lejanas

```
Those + Plural Noun
```

Examples:

- **those cars**
- **those houses**
- **those students**
- **those ideas**

> **Those students** are from Mexico.

---

# 12. Demonstratives — Quick Table

|Demonstrative|Number|Distance|Example|
|---|---|---|---|
|**this**|Singular|Near|this book|
|**these**|Plural|Near|these books|
|**that**|Singular|Far|that book|
|**those**|Plural|Far|those books|

### Regla fundamental

```
THIS  → Singular + Near
THESE → Plural + Near

THAT  → Singular + Far
THOSE → Plural + Far
```

---

# 13. Demonstrative Pronouns

`this, that, these, those` también pueden funcionar como **pronombres**, es decir, pueden aparecer **sin un sustantivo después**.

### Determiner

```
This + Noun
```

> **This book** is mine.

### Pronoun

```
This
```

> **This** is mine.

Compara:

|Determiner|Pronoun|
|---|---|
|this book|this|
|that car|that|
|these books|these|
|those cars|those|

---

# 14. Determiner vs Pronoun

Esta diferencia es importante para TOEFL.

### Determiner

Modifica un sustantivo.

```
Determiner + Noun
```

> **Those students** are studying.

`those` → determiner  
`students` → noun

### Pronoun

Reemplaza al sustantivo.

```
Pronoun
```

> **Those** are studying.

`those` → pronoun

---

# 15. Possessive vs Demonstrative

No los confundas:

|Possessive|Demonstrative|
|---|---|
|my|this|
|your|that|
|his|these|
|her|those|
|its||
|our||
|their||

### Possessive

Indica **a quién pertenece**:

> **My book**

→ el libro pertenece a mí.

### Demonstrative

Indica **cuál**:

> **This book**

→ este libro.

Pueden combinarse con otros determinantes permitidos:

> **all my books**

> **both these books**

Pero:

> ❌ **the my book**

> ❌ **the this book**

# 16. Resumen general

|Categoría|Palabras|Función|
|---|---|---|
|Articles|a, an, the|Definir el sustantivo|
|Possessive Determiners|my, your, his, her, its, our, their|Indicar posesión|
|Demonstratives|this, that, these, those|Señalar|
|Quantifiers|some, any, many, much, few, little, etc.|Indicar cantidad|
|Distributives|each, every, either, neither|Distribuir/individualizar|
|Numbers|one, two, three...|Indicar cantidad exacta|
|Interrogatives|which, what, whose|Formular preguntas|
|Negative|no|Indicar ausencia|
