
# Noun Phrases

### Definition

Una **Noun Phrase (NP)** es un grupo de palabras cuyo elemento principal es un **sustantivo (noun)** o un **pronombre (pronoun)**.

El sustantivo principal se llama **Head Noun**.

Ejemplo:

> The intelligent student

El **Head Noun** es:

> student

Todo lo demás modifica o determina a `student`.

---

### Basic Structure

```
Noun
```

Ejemplos:

- student
- house
- information
- books

Una sola palabra también puede funcionar como **Noun Phrase**.

---

# 2. Determiner + Noun

### Structure

```
Determiner + Noun
```

Los **determiners** especifican o limitan al sustantivo.

Ejemplos:

- a book
- the car
- my house
- this student
- some information
- every student
- each person

### Common Determiners

- a / an
- the
- this / that
- these / those
- my / your / his / her / its / our / their
- some / any
- each / every
- no
- all
- one

---

# 3. Adjective + Noun

### Structure

```
Adjective + Noun
```

Ejemplos:

- beautiful city
- expensive car
- intelligent student
- difficult exam
- useful information

El **Head Noun** sigue siendo el sustantivo:

> beautiful **city**

> expensive **car**

---

# 4. Determiner + Adjective + Noun

### Structure

```
Determiner + Adjective + Noun
```

Ejemplos:

- a beautiful city
- an expensive car
- the intelligent student
- my new computer
- this difficult exam

### Analysis

> **The intelligent student**

```
The → Determiner
intelligent → Adjective
student → Head Noun
```

---

# 5. Multiple Adjectives

Una Noun Phrase puede contener más de un adjetivo.

### Structure

```
Determiner + Adjective + Adjective + Noun
```

Ejemplos:

- a beautiful old house
- an expensive new computer
- the large red car
- my small black backpack

### Adjective Order

Cuando utilizamos varios adjetivos, normalmente siguen un orden determinado:

```
Opinion → Size → Age → Shape → Color → Origin → Material → Purpose → Noun
```

Ejemplo:

> a beautiful small old red Italian leather bag

No necesitas memorizar inmediatamente todos los tipos, pero para **C1** sí conviene reconocer este orden.

---

# 6. Noun + Noun

Un sustantivo también puede modificar a otro sustantivo.

### Structure

```
Noun + Noun
```

El segundo sustantivo normalmente es el **Head Noun**.

Ejemplos:

- school bus
- coffee shop
- computer science
- English teacher
- university student
- car door

### Example

> school **bus**

```
school → modifier
bus → Head Noun
```

No estamos hablando de una "escuela", sino de un **autobús**.

---

# 7. Possessive + Noun

### Structure

```
Possessive + Noun
```

Ejemplos:

- my computer
- her brother
- John's car
- the student's book
- their house

También podemos combinarlo con adjetivos:

```
Possessive + Adjective + Noun
```

- my new computer
- her older brother
- John's expensive car

---

# 8. Noun + Prepositional Phrase

Una Noun Phrase puede tener una **prepositional phrase** que proporciona información adicional sobre el sustantivo.

### Structure

```
Noun + Preposition + Noun
```

Ejemplos:

- students **in the classroom**
- the book **on the table**
- the house **near the university**
- information **about the exam**

La prepositional phrase funciona como modificador del sustantivo.

---

# 9. Determiner + Adjective + Noun + Prepositional Phrase

Aquí empezamos a tener Noun Phrases más largas.

### Structure

```
Determiner + Adjective + Noun + Prepositional Phrase
```

Ejemplos:

- the intelligent student **in my class**
- a beautiful house **near the beach**
- an expensive computer **from Japan**
- the difficult exam **at the university**

### Example

> The intelligent student in my class

```
The → Determiner
intelligent → Adjective
student → Head Noun
in my class → Prepositional Phrase
```

El **Head Noun** sigue siendo:

> student

---

# 10. Noun Phrase with Relative Clause

Una Noun Phrase también puede incluir una **relative clause**.

### Structure

```
Determiner + Adjective + Noun + Relative Clause
```

Ejemplo:

> The intelligent student **who studies every day** passed the exam.

```
The → Determiner
intelligent → Adjective
student → Head Noun
who studies every day → Relative Clause
```

Otros ejemplos:

- The book **that I bought yesterday**
- The woman **who lives next door**
- The computer **which I purchased last year**
- The students **who passed the exam**

Esto será especialmente importante cuando estudies **Relative Clauses**, porque una relative clause puede funcionar como modificador de un sustantivo.

---

# 11. Noun Phrase with Multiple Modifiers

Una Noun Phrase puede contener varios tipos de modificadores simultáneamente.

### Structure

```
Determiner + Adjective + Noun + Prepositional Phrase + Relative Clause
```

Ejemplo:

> The intelligent student in my class who studies every day

Aquí:

```
The → Determiner
intelligent → Adjective
student → Head Noun
in my class → Prepositional Phrase
who studies every day → Relative Clause
```

Todo el conjunto funciona como una sola **Noun Phrase**.

---

# 12. Head Noun

El **Head Noun** es la palabra principal de la Noun Phrase.

Todo lo demás proporciona información sobre él.

### Example

> The three expensive new computers in the laboratory

```
The → Determiner
three → Number
expensive → Adjective
new → Adjective
computers → Head Noun
in the laboratory → Prepositional Phrase
```

El Head Noun es:

> **computers**

---

# 13. Noun Phrases with Quantifiers

También podemos utilizar quantifiers.

### Structure

```
Quantifier + Noun
```

Ejemplos:

- some students
- many books
- several questions
- few people
- little information
- much money
- every student
- each person

También podemos combinarlos:

```
Quantifier + Adjective + Noun
```

- several important questions
- many interesting books
- a few difficult exams
- little useful information

---

# 14. Noun Phrase as Subject

Una Noun Phrase puede funcionar como el **subject** de una oración.

### Structure

```
Noun Phrase + Verb + Complement
```

Ejemplo:

> **The intelligent student** passed the exam.

Toda esta parte:

> **The intelligent student**

es el **Subject**.

---

# 15. Noun Phrase as Object

Una Noun Phrase también puede funcionar como **object**.

### Structure

```
Subject + Verb + Noun Phrase
```

Ejemplo:

> I bought **a new computer**.

La Noun Phrase:

> **a new computer**

es el objeto de `bought`.

---

# 16. Cómo identificar una Noun Phrase

Cuando estés haciendo un ejercicio del TOEFL, busca primero el **Head Noun**.

Por ejemplo:

> The three intelligent students from Mexico passed the exam.

Primero identifica:

> students

Después observa qué palabras pertenecen a ese sustantivo:

```
The → Determiner
three → Number
intelligent → Adjective
students → Head Noun
from Mexico → Prepositional Phrase
```

Toda la Noun Phrase es:

> **The three intelligent students from Mexico**

---

# 17. Estructura general

Una Noun Phrase puede llegar a tener una estructura bastante compleja:

```
Determiner + Number + Adjective(s) + Noun Modifier + Head Noun + Prepositional Phrase + Relative Clause
```

Ejemplo:

> The three intelligent university students from Mexico who passed the exam

```
The → Determiner
three → Number
intelligent → Adjective
university → Noun Modifier
students → Head Noun
from Mexico → Prepositional Phrase
who passed the exam → Relative Clause
```
